# 知芽前端静态演示包

- 对应提交：`ebe5593db914a1baf01139282b6d04d81410b699`（PR #56 分支 `feat/frontend-layout-polish` 最新提交）
- 生成日期：2026-11-20
- 用途：课程评审时快速查看首页轮播、绘本馆翻页和个人中心布局

## 打开方式

直接双击 `index.html`，用浏览器打开即可，不需要启动服务，也不需要 Node.js 或后端。

## 覆盖页面

- **首页**：精选绘本书架、左右切换按钮、今日推荐、阅读计划
- **绘本馆**：3D 绘本轮播、左右切换、底部圆点、绘本详情入口
- **个人中心**：个人资料、儿童档案、我的书架、成长记录、阅读计划
- 阅读页：本地预览会话（不写入后端）

## 模拟数据范围

- 书目、封面、页面、提问和个人中心数据均为前端本地模拟数据。
- 个人中心使用**模拟登录**（演示家长 / 小芽），不会发起真实登录请求。
- 未连接后端，因此登录、注册、阅读进度同步、语音等真实接口不可用。
- 本演示包只用于查看前端布局和交互，不作为后端功能验收证据。

## 生成方式

以 PR #56 的 `frontend/` 源码为基础，使用 `vite.html.config.js`（`base: './'`、`assetsDir: 'bundles'`）构建，再由 `scripts/inline-html-review.cjs` 内联 CSS/JS，并把 `/assets`、`../assets` 统一改为同级相对路径，保证 `file://` 下可直接打开。

为使个人中心可预览，静态演示构建中加入了 `window.__ZHIYA_STATIC_DEMO__` 开关：仅在该演示包内注入模拟登录和本地数据，不改变 PR #56 的默认行为。
